# Perf Painting Ltd — Website Concept

A custom React + Vite website concept based on publicly available information about Perf Painting Ltd in Christchurch, New Zealand.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Research basis

The business name, Christchurch location, service descriptions and service-area names are based on the public Perf Painting Ltd profile on Builderscrack:
https://builderscrack.co.nz/tradies/4qb5907w/perf-painting-ltd

The profile describes residential, commercial and industrial painting; interior and exterior work; new builds; roof painting; plastering; patch repairs; water blasting; spray painting; and specialised coatings. It lists Ashburton, Banks Peninsula, Christchurch, Hurunui, Mackenzie, Selwyn, Timaru, Waimakariri and Waimate as service areas.

The profile references Instagram as `@Perf_Painting_Limited`:
https://www.instagram.com/perf_painting_limited/

## Important before publishing

- This is an unsolicited website concept, not an official Perf Painting Ltd website.
- Confirm the business is currently trading and accepting work. The Builderscrack profile currently displays an "isn't currently active" notice.
- Confirm all services and service areas directly with the business.
- No phone number, email, street address, opening hours, licence, insurance or customer reviews have been invented or added.
- Portfolio imagery is illustrative stock photography, not verified Perf Painting Ltd project work. Replace with approved photos from the company's own jobs.
- The enquiry form is frontend-only and does not send or store enquiries. Connect a backend or form service before launch.
- The displayed service copy is a proposed marketing rewrite; have the business approve it.
